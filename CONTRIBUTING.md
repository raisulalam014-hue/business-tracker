# Contributing to BizLedger

Thank you for your interest in contributing to **BizLedger**!

## How to Contribute

1. **Fork the Repository**:
   Click the **Fork** button at the top right of this page.

2. **Clone your Fork**:
   ```bash
   git clone https://github.com/raisulalam014-hue/business-tracker.git
   cd business-tracker
   ```

3. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/my-new-feature
   ```

4. **Make Changes**:
   - Keep JavaScript clean, vanilla, and accessible.
   - Use Tailwind CSS utility classes.
   - Test offline capabilities and `localStorage` persistence.

5. **Commit and Push**:
   ```bash
   git commit -m "Add feature: my new feature"
   git push origin feature/my-new-feature
   ```

6. **Submit a Pull Request**:
   Open a pull request describing the changes and why they are needed.

## Reporting Issues
If you encounter a bug or have a suggestion, please open an Issue on GitHub with details and steps to reproduce.
